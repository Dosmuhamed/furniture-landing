# LUNDA — сайт, который вы обставляете, пока листаете

Концепт сайта-визитки для вымышленной мебельной мастерской **LUNDA** (Алматы). Проект для портфолио: только фронтенд, без бэкенда.

**Стек:** React 19 · TypeScript · Vite · three.js + React Three Fiber · Framer Motion · Lenis

## Идея

Вместо привычной ленты секций вся страница — одна 3D-гостиная на весь экран. Прокрутка ведёт по главам, и в каждой главе в комнату добавляется мебель, а камера сама подлетает к новому предмету.

| Глава | Что происходит |
| --- | --- |
| 1. Чертёж | Пустая комната в виде архитектурного чертежа: синий фон, белые контуры, размеры, штамп листа |
| 2. Стены | Стены «вырастают» из пола, чертёж растворяется. Можно выбрать цвет стен и пол |
| 3. Диван | Диван падает в комнату, камера подлетает к нему. 3 модели, 6 тканей |
| 4. Кресло | Кресло у окна и журнальный столик |
| 5. Свет | Наступает вечер: в окне звёзды, торшер светит тёплым светом |
| 6. План | Вид сверху с габаритами каждого предмета, выбор ковра |
| 7. Детали | Стеллаж, растение и картина |
| 8. Ваша комната | Полный конструктор: вращение, все настройки, готовые стили (Скандинавия, Japandi, Бохо, Лофт), снимок в PNG |
| Смета | Лист-спецификация: автоматически нарисованный план комнаты, таблица позиций с ценами и штамп чертежа |

Всё, что читатель выбирает по ходу, сохраняется: в конце у него его собственная комната и смета. Сумма в шапке пересчитывается на лету, любой набор можно отправить в корзину.

## Как это устроено

- Мебель собрана из примитивов three.js, без загружаемых 3D-моделей; текстуры пола, ковров и картин рисуются на `<canvas>`.
- Положение прокрутки переводится в «номер главы» (`src/lib/scroll.ts`) и читается в каждом кадре сцены — без ререндеров React.
- Камера плавно летит между ракурсами глав (`src/configurator/Scene.tsx`); на десктопе картинка сдвигается вбок под текст, на телефоне — вверх над карточкой.
- План в смете строится по тем же координатам и габаритам, что и 3D-сцена (`footprints` и `placement` в `catalog.ts`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Публикация на GitHub Pages

В `vite.config.ts` указан `base: '/furniture-landing/'` — если репозиторий называется иначе, поменяйте путь. Workflow `.github/workflows/deploy.yml` собирает и публикует сайт при пуше в `main`; в настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.

## Структура

```
src/
  chapters.ts    тексты и состав глав
  configurator/  3D: каталог, мебель, комната-чертёж, камера, панель конструктора, общее состояние
  sections/      Story (главы поверх сцены) и Spec (смета-чертёж)
  components/    шапка, корзина, загрузчик
  lib/           прокрутка, форматирование цен
```
